# Rodada mobile: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** melhorar a experiência no celular: abertura A do menu, botão da Vega que não cobre conteúdo, ciclo sem fixar, alvos de toque e texto no tamanho certo, carrosséis na IA e no "No ar", barra de progresso e resposta ao toque.

**Spec:** `docs/superpowers/specs/2026-11-08-mobile-design.md`

## Global Constraints
- Sem `backdrop-filter`. Cores só por tokens.
- Animar só `transform` e `opacity`; a exceção é o `clip-path` do círculo do menu.
- Movimento reduzido deixa só fades curtos.
- Gate por tarefa: `npx pnpm@10.28.0 vitest run <arquivos>`.
- Gate final: suíte completa, `tsc`, `biome` e `knip` (via `rtk proxy`).
- Commit só depois do gate passar. A mensagem termina com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. Abrir e fechar o menu muito rápido, várias vezes: o estado não fica preso, o overlay não fica órfão e a rolagem volta.
2. Movimento reduzido: o menu abre e fecha sem círculo nem deslocamento.
3. O botão da Vega volta quando a pessoa para de rolar no fim da página e ao voltar para cima.
4. O carrossel com 1 item ou com a largura toda visível: o contador continua certo.
5. Desktop sem regressão: o ciclo continua fixado, o "No ar" continua horizontal fixado e a grade da IA continua a mesma.

### Task 1: Menu com abertura A
**Files:** `src/shared/shell/site-menu.tsx`, `src/shared/shell/menu-motion.ts` (novo), teste `src/shared/shell/__tests__/site-menu.test.tsx`.

**Produces:**
- `openMenuMotion(els: MenuMotionEls, origin: {x,y}, reduced: boolean): Animation[]`;
- `closeMenuMotion(...)`, que devolve uma Promise resolvida no fim;
- `MenuMotionEls = { page: HTMLElement|null; bg: HTMLElement; links: HTMLElement[]; numbers: HTMLElement[]; socials: HTMLElement[] }`.

**Steps:**
- **Testes:**
  - o botão mostra o ícone de duas barras e alterna `aria-expanded`;
  - o texto alterna entre "Menu" e "Fechar";
  - os links ficam num `nav` com `data-menu-links`;
  - as redes têm `min-h-[46px]`;
  - ao fechar, o overlay continua montado até a Promise de fechar resolver; depois sai do DOM;
  - com movimento reduzido, nenhum `clip-path` é animado;
  - abrir e fechar rápido (open → close → open) termina aberto e com `overflow` hidden.
- **Implementar:**
  - WAAPI (`element.animate`), com guarda para quando `animate` não existir (testes): aí só troca o estado;
  - estado `phase: 'closed' | 'open' | 'closing'`;
  - `navigator.vibrate?.(10)` ao abrir;
  - `main` como página de fundo, para o recuo (`document.getElementById('main-content')`);
  - o botão do menu fica acima do overlay com `z-[61]`.
- Commit `feat(shell): menu opens from the button in a circle, links rise into the thumb zone`.
